Use an explicitly allocated scratch sector for destructive flash bring-up. Identify, erase/blank-check, program a known pattern spanning pages through split commands, then compare every byte. Record board revision, firmware commit, host/tool versions, voltage conditions and analyzer captures. Never perform the scratch test on retained sessions.

Acceptance requires all mandatory requirements to have reproducible evidence, closure of storage format/throughput decisions, no unexplained nominal sequence loss, bounded error behavior, and peer approval. Generated builds establish compilation only, not correct USB enumeration, memory sizing, acquisition, persistence or recovery.
