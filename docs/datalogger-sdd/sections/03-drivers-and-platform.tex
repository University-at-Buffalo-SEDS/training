The schematic's STM32 and flash sheets establish the shared bus and PB14 selection. Sensor interrupt lines are unconnected, so polling is the baseline. Verify the fitted part suffix, supply, mounting axes and oscillator components against the physical board before qualification.

The SPI adapter serializes complete transactions: take an inheritance mutex, ensure other selects are high, assert one select, exchange command/address/data, deselect and unlock on every path. Keep configuration changes under the same mutex if later devices require different SPI settings. Transfers have finite timeouts; interrupt callbacks do not block on this mutex.

BMI088 initialization checks both identities, reset delays, power/measurement settings and sample scaling. BMP390 initialization loads compensation coefficients and checks data-ready/status; stale pressure remains explicitly stale. Exact range, bandwidth and oversampling settings require review and golden-vector tests. The flash driver supports bounded ID/status/read/program/sector-erase operations; it does not guess geometry after an ID mismatch.
