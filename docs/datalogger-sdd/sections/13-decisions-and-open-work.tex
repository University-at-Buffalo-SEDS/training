Role assignments are responsibilities, not claims that individuals have accepted work. Assign people and track each item through issues/PRs. An optional Kalman filter is deferred; add its state model, noise assumptions, initialization and validation as a separate reviewed feature if requested.

The checked-in USBX memory pool is currently 1024 bytes, while the generated application requests a 1024-byte USB memory region and an additional 1024-byte thread stack plus allocator overhead. It is insufficient as a runtime design and must be resized before claiming working USB. This document does not silently treat the generated values as qualified allocations.
